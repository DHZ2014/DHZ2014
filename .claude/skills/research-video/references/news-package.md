# 财经新闻包装（竖屏版）

改编自 lemo-opuscar `styles/news-package/STYLE.md`（MIT），原版是 16:9，这里重排为 1080×1920 竖屏。规则只学语法：不模仿任何电视台的 logo、片头、字体、配色和音乐，也不在片中点名。

## 本质
1. **一套包装系统贯穿全片**：品牌板（平行四边形）、强调色小标签 tab、纸色标题条 strap、墨色卡片加强调色顶边、等宽字体的日期线、印章。观众先读懂系统，再读字。
2. **节目顺序**：片头 → 串联单（今天看 N 件事）→ 逐条故事 → 结论 → 串联单回来变成跟踪清单并逐行打勾 → 片尾卡。
3. **一屏一个事实**：价格、突破、比例、对比、结论，各占一屏。
4. **标题条承载标题**：从第一条故事起常驻底部，换内容时竖向翻转；跟踪清单开始时滑出。
5. **画面干净**：不压字幕、不加滚动新闻条；字幕另出 SRT。

## 部件
| 部件 | 做法 |
|---|---|
| 片头 0–1.9 s | 两道斜线（0.04、0.10 s）→ 品牌板带回弹砸入、扩散环和震动（0.16–0.42）→ 字母逐个落下 → 日期线从中间展开 → 一道高光 → 1.45–1.9 s 品牌板飞到右上角变成台标，同时色带把串联单擦进来。0.4 s 内要有一个打击音 |
| 串联单 | 上方大号日期（Barlow 800 强调色）+ 月份星期；下方 N 行（960×150），左侧强调色编号块；按口播逐行竖向翻入（back ease）并扫过高光 |
| 翻牌板 | 每个字符一块（176×300），上下两半分别裁切；新旧值在同一块板上翻，变化一眼可读；逐块错开 0.07 s，每块配一声 clack |
| 门槛线 | 金色虚线标门槛；柱或线头越过门槛时变强调色，配扩散环、震动、ding；坐标轴只画数据支持的范围 |
| 比例条卡片 | 眉题（来源 · 日期）、标题、同一比例尺的整体与部分、百分比徽章、底部情境标签；数值滚动 |
| 印章 | 强调色双线框、墨底、−6° 到 −10°；0.16 s 从 1.9 倍砸到 1 倍并带扩散环；每个故事最多一个 |
| 转场 | 故事之间用竖向色带从左向右扫（强调色 84px + 墨色 5px + 金色 14px，0.3 s），**每个场景自带标题条**，色带扫过时新旧标题条各画在各自一侧；故事内部硬切加低频 thump；片尾卡用斜向强调色擦除 |
| 片尾卡 | 品牌板从台标飞回中央；中文标题、英文斜体副题、横线；「个人研究笔记 · 不构成投资建议」、来源与持仓披露 |

## 字体
Noto Sans SC 900（标题、标题条）/ 700（标签）；Barlow Condensed 800（数字、品牌）/ 600（英文副行）；IBM Plex Mono 500（日期线、来源、坐标，全大写加字距）。全部 OFL，`setup.sh` 下载到本地。标签一律中英双行，不换行。

## 声音
E 小调 120 BPM 新闻主题（片头之后进拍，八分音符贝斯 + 铺底 + 每两小节一个琶音动机），旁白出现时闪避约 70%；片尾 E 大三和弦。音效：色带 whoosh、翻牌 clack、印章 thump + crash、越线 ding、故事内硬切低频 thump、清单打勾 ding。
